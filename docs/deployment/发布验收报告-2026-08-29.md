## 本阶段发现并修复

- Docker 启动后 Windows 动态保留 `7979–8078` 端口段，导致原端口 `8004` 无法绑定；项目最终后端端口已统一调整为 `15200`，端到端脚本仍支持通过 `DEVMIND_E2E_BACKEND` 覆盖。
- 本地 PyJWT 安装目录不完整导致 JWT 签发失败；重新安装锁文件中的 `pyjwt==2.13.0` 后恢复，业务代码无需修改。
- 移动端回答中的长类名和路径会撑大 Flex 子项；已限制回答卡最小宽度并允许技术字符串安全换行。
- 回答中的粗体与行内代码标记曾直接显示；现使用无 HTML 注入的 React 节点进行轻量格式化。
- “继续追问”已在写入预置问题后自动聚焦底部输入框。
