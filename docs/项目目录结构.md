# DevMind-AI 项目目录结构

> 本目录结构按本仓库当前文件整理。

## 目录树

```text
DevMind-AI/
├── app.py                         # T8 FastAPI 问答服务入口（端口 8003）
├── new_main.py                    # T8 集成编排：意图->FAQ->RAG->转人工
├── config.local.ini.example      # 本地数据库与检索配置模板（真实 config.ini 不提交）
├── requirements.txt
├── pyproject.toml
├── Dockerfile / entrypoint.sh     # T11 私有化部署
├── locust_test.py                 # T11 压测
├── base/                          # 配置与通用日志
├── postgres_qa/                   # T5 高频 FAQ 精确匹配（PostgreSQL + BM25）
│   ├── cache/  db/  retrieval/  utils/  data/
│   └── sql_main.py
├── rag_qa/                        # 早期 RAG 组件与数据结构
│   ├── classify_data/
│   ├── core/                      # vector_store、rag_system、query_classifier 等
│   ├── data/
│   ├── edu_document_loaders/      # T2 loader 参考
│   ├── edu_text_spliter/          # T3 切分参考
│   ├── models/                    # bge-m3 / reranker / 文档分段模型
│   └── rag_assesment/             # T10 评估流程参考
├── internal_kb_qa/                # 企业版核心开发包（T1-T8、T10、T13、T14）
│   ├── api/                       # T8 路由、SSO 鉴权、请求/响应模型
│   ├── core/                      # T3/T4/T5/T6/T7/T13/T14 模块
│   ├── data/                      # T1 raw/processed/faq/desensitization/classify_data
│   ├── document_loaders/          # T2 PDF/Word/Markdown/Confluence/OpenAPI
│   ├── text_splitters/            # T3 递归切分与代码切分
│   ├── models/
│   ├── rag_assesment/             # T10 eval_set.json + RAGAS 脚本
│   └── scripts/                   # 采集/脱敏/FAQ构建/入库脚本
├── client-backend/                # T12 客户端后端服务
├── static/                        # T9 React 前端
├── docker/                        # T11 base_app / milvus_redis
├── docs/
│   ├── api/                       # T8 接口文档
│   ├── eval/                      # T10 评估报告
│   ├── deployment/                # T11 部署说明
│   └── tasks/                     # 任务分工文档归档位
├── tests/                         # unit / integration / permission / load
├── scripts/  notebooks/  logs/  docker_logs/
└── .gitignore
```

## 约定

1. 模型权重、数据库卷、日志不入库 Git。
2. 所有文档带 `team/system/security_level` 元数据，检索时强制注入权限过滤。
3. T8 接口契约是前后端并行开发的基准，必须先定稿。
