# DevMind AI 登录页接口契约

服务入口：`http://localhost:15200/api/v1`。生产环境使用 HTTPS。当前实现签发 Bearer Access Token，前端保存后随业务请求发送；生产化可在不改变页面流程的前提下补充刷新令牌 Cookie。

认证相关的数据表与安全约束见：[工作台数据库设计.md](../database/工作台数据库设计.md)。

## 统一响应

```json
{ "request_id": "req_xxx", "data": {}, "error": null }
```

失败时 `data` 为 `null`，`error` 例如 `{ "code": "INVALID_CREDENTIALS", "message": "账号或密码错误" }`。为避免账号枚举，登录、注册和验证码接口对不存在账号返回同一类通用提示。

## 账号密码登录

`POST /auth/login`

```json
{ "account": "zhang", "password": "<password>" }
```

成功返回：

```json
{
  "request_id": "req_01",
  "data": {
    "access_token": "eyJ...",
    "token_type": "Bearer",
    "user": { "id": "usr_01", "display_name": "张工程师", "department": "研发部" }
  },
  "error": null
}
```

`account` 可为用户名或手机号。登录状态有效期由服务端 JWT 配置决定。

同一账号连续 5 次密码错误后临时锁定 15 分钟，锁定期间返回 `423 ACCOUNT_TEMPORARILY_LOCKED`。登录同时按账号和客户端 IP 执行 Redis 原子限流，超过限制返回 `429 RATE_LIMITED` 和 `Retry-After`。

## 手机验证码

### 发送验证码

`POST /auth/send-code`

```json
{ "phone": "13800138000" }
```

验证码同时用于登录和注册。开发环境响应可包含 `debug_code` 方便联调；生产环境不得返回验证码。当前限制为同一手机号 60 秒一次、每天最多 10 次，同一 IP 每小时最多 30 次；验证码校验失败也单独限频。

### 手机登录

`POST /auth/login/sms`

```json
{ "phone": "13800138000", "sms_code": "123456" }
```

返回结构与账号密码登录相同。手机号未注册时返回 `PHONE_NOT_REGISTERED`，前端提示用户切换至注册。

## 注册账号

### 账号密码注册

`POST /auth/register`

```json
{
  "username": "zhang",
  "password": "<password>",
  "nickname": "张工程师",
  "phone": "13800138000",
  "sms_code": "123456",
  "team": "default"
}
```

密码策略由服务端校验，建议至少 12 位并拒绝已泄露密码。成功后创建用户和本地身份，并返回登录令牌结构。

注册统一要求手机验证码，成功后立即签发登录令牌。手机号或用户名已绑定时返回对应冲突错误。

## 会话与退出

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/logout` | 将当前 Access Token 加入 Redis 黑名单；前端清除本地令牌并跳转 `/` |
| GET | `/me` | 获取已登录用户的姓名、部门、头像与权限摘要 |

`POST /auth/logout` 无论会话是否已失效，都返回成功，确保客户端能安全地回到展示页。

## 前端状态映射

| 页面动作 | 调用接口 | 成功后的页面行为 |
| --- | --- | --- |
| 默认账号密码登录 | `/auth/login` | 保存访问令牌并跳转 `/workspace` |
| 点击“其他登录方式 → 手机验证码登录” | 无请求 | 切换为手机号表单 |
| 点击“获取验证码” | `/auth/send-code` | 显示倒计时，禁止重复发送 |
| 手机验证码登录 | `/auth/login/sms` | 跳转 `/workspace` |
| 注册账号 | `/auth/register` | 验证手机号后自动登录并跳转 `/workspace` |
| 工作台退出登录 | `/auth/logout` | 清除本地访问令牌并跳转 `/` |

上述登录、注册、验证码和退出接口均已由正式后端实现并接入前端。密码哈希、验证码校验、JWT 签发与退出黑名单均由后端负责；前端不模拟认证成功。

已认证接口按 JWT 用户维度执行 Redis 原子限流，默认每分钟 300 次。限流键只保存账号、手机号或 IP 的 SHA-256 摘要，不保存原始标识。
