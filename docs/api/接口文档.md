# DevMind AI 工作台 API 文档

服务入口：`http://localhost:15200`。启动命令：`uvicorn app.main:app --reload --port 15200`。

正式路由由 `backend/app/api/__init__.py` 聚合。`backend/app/api/workspace.py` 仅保留为前端联调参考，不注册到正式服务。

## 当前正式接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/api/v1/auth/send-code` | 发送手机验证码 |
| POST | `/api/v1/auth/register` | 注册账号 |
| POST | `/api/v1/auth/login` | 账号密码登录 |
| POST | `/api/v1/auth/login/sms` | 手机验证码登录 |
| POST | `/api/v1/auth/logout` | 退出登录 |
| GET | `/api/v1/me` | 当前用户 |
| GET | `/api/v1/me/profile` | 当前用户完整档案、所属组织与可编辑字段 |
| PATCH | `/api/v1/me/profile` | 保存档案与个人偏好并记录审计日志 |
| GET | `/api/v1/knowledge-bases` | 当前用户可访问的知识库列表 |
| POST | `/api/v1/knowledge-bases` | 创建知识库，创建者成为管理员 |
| GET | `/api/v1/knowledge-bases/{id}` | 知识库详情与统计 |
| PATCH | `/api/v1/knowledge-bases/{id}` | 管理员修改知识库 |
| DELETE | `/api/v1/knowledge-bases/{id}` | 管理员归档知识库 |
| GET | `/api/v1/knowledge-bases/{id}/members` | 管理员查看成员 |
| PUT | `/api/v1/knowledge-bases/{id}/members/{user_id}` | 管理员新增成员或修改角色 |
| DELETE | `/api/v1/knowledge-bases/{id}/members/{user_id}` | 管理员移除成员 |
| GET/POST | `/api/v1/documents` | 查询文档/上传并创建处理任务 |
| GET/PATCH/DELETE | `/api/v1/documents/{id}` | 详情/修改/软删除文档 |
| POST | `/api/v1/documents/{id}/reindex` | 重新解析、分块和向量化 |
| GET | `/api/v1/documents/{id}/chunks` | 查看文档分块 |
| GET | `/api/v1/documents/{id}/task` | 查询最近处理任务进度 |
| GET/POST | `/api/v1/sessions` | 查询/创建当前用户会话 |
| GET | `/api/v1/sessions/{id}` | 会话与消息上下文 |
| POST | `/api/v1/messages` | 创建用户问题和待生成 AI 消息 |
| GET | `/api/v1/messages/{id}` | 查询已持久化消息 |
| WS | `/api/v1/chat/stream` | 一次性票据鉴权的 RAG 流式回答 |
| GET | `/api/v1/messages/{id}/citations` | 回答引用与可信度 |
| GET | `/api/v1/citations/{id}` | 引用片段详情 |
| POST | `/api/v1/retrieval/test` | Query 改写、混合召回和重排序测试 |
| GET | `/api/v1/knowledge/docs` | PostgreSQL 文档元数据列表 |
| GET | `/api/v1/knowledge/docs/{id}` | 文档元数据详情 |
| GET | `/api/v1/faq` | FAQ 列表 |
| GET | `/api/v1/faq/{id}` | FAQ 详情 |
| POST | `/api/v1/faq/search` | FAQ 问题查询与 Redis 缓存 |
| GET | `/metrics` | Prometheus 指标；生产环境使用独立 Metrics Token |

除注册、登录、验证码和健康检查外，接口必须携带 `Authorization: Bearer <access_token>`。FAQ 缓存键包含组织、用户密级和部门作用域，列表、详情与搜索结果均执行相同的内容权限过滤，禁止跨组织复用缓存结果。

## 待持久化实现的工作台接口

收藏、回答反馈和工作台默认偏好仍按各接口契约开发，不能将 `workspace.py` 的内存数据用于生产环境。个人资料、知识库权限、文档索引以及正式 RAG 问答链路已经持久化。

所有 HTTP 成功响应统一为：

```json
{ "request_id": "req_xxx", "data": {}, "error": null }
```

完整的请求字段、流式事件协议、页面映射与后续接口规划见：[工作台前后端接口契约.md](工作台前后端接口契约.md)。登录、注册、短信验证码与退出登录的约定见：[登录页接口契约.md](登录页接口契约.md)。知识库与文档管理的页面数据、异步处理和接口约定见：[知识库与文档管理接口契约.md](知识库与文档管理接口契约.md)。检索测试、历史记录、我的收藏和系统设置的接口约定见：[工作台辅助功能接口契约.md](工作台辅助功能接口契约.md)。个人资料保存与数据验证见：[个人信息接口契约.md](个人信息接口契约.md)。
