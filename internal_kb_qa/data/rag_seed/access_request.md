# 权限与账号申请指引

本文档说明公司内部系统、数据库、代码仓库等权限和账号的申请方式。

## 一、通用申请流程

1. 登录公司内部工单系统。
2. 选择「权限申请」类型。
3. 填写申请人、申请系统、权限类型、申请原因和使用期限。
4. 提交后由对应系统负责人审批。
5. 审批通过后由管理员开通。

所有权限申请均需要人工审批，系统不会自动开通权限。

## 二、常见权限类型

### Git 仓库权限

- 申请内容：项目仓库地址、需要的角色（Developer / Maintainer / Reporter）。
- 权限说明：Developer 可以推送代码；Maintainer 可以管理分支和合并请求；Reporter 只能查看。

### MySQL 数据库权限

- 申请内容：数据库名、环境（测试 / 生产）、权限范围（只读 / 读写）、使用期限。
- 生产数据库默认只批准只读权限。
- 读写权限必须附加业务负责人审批。

### VPN 权限

- 申请内容：VPN 类型、使用人、使用期限。
- 默认开通周期为 30 天，到期需要重新申请。

### Jenkins / CI 权限

- 申请内容：需要访问的项目、需要的操作权限（查看 / 构建 / 配置）。
- 构建权限默认开放给研发人员，配置权限需要项目负责人审批。

### 生产环境访问权限

- 生产服务器默认不开放直接登录。
- 需要紧急排查时，通过运维审批后开通临时权限，一般 2 小时后自动回收。

## 三、账号开通

### 新员工账号开通

新员工入职后，由 HR 在入职流程中发起账号开通，通常包括：

- 公司邮箱
- OA / 工单系统账号
- GitLab 账号
- 内部 IM 账号
- VPN 账号

### 第三方合作人员账号

合作人员账号由对接负责人申请，必须设置有效期，到期自动禁用。

## 四、常见问答对

### 问：我要申请生产 MySQL 只读权限，怎么操作？

答：在工单系统提交权限申请单，类型选择 MySQL，环境选择生产，权限选择只读，填写使用原因和使用期限，提交后等待数据库负责人审批。

### 问：新同事需要开通 GitLab 权限怎么办？

答：在工单系统提交 Git 权限申请，填写仓库地址和角色，通常 Developer 即可满足日常开发需要。

### 问：VPN 权限到期了怎么办？

答：VPN 权限到期后需要重新提交权限申请，填写使用人和使用期限，审批通过后会重新开通。

### 问：生产服务器能不能直接登录？

答：不能直接登录。需要提交生产环境访问权限申请，说明紧急原因，审批通过后获得临时权限，到期自动回收。

### 问：权限申请一般多久能审批完？

答：普通权限一般在 1 个工作日内处理；生产权限和紧急权限会走加急审批，具体进度可在工单系统查询。
