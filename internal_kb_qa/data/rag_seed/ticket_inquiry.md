# 工单进度查询说明

本文档说明如何查询工单进度、理解工单状态，以及常见催办方式。

## 一、工单查询方式

### 方式一：工单系统查询

1. 登录公司内部工单系统。
2. 进入「我的工单」页面。
3. 输入工单号或关键词搜索。
4. 查看工单状态、处理人和更新时间。

### 方式二：通过问答系统查询

可以直接提问，例如：

- “我昨天提的权限申请工单处理到哪了？”
- “帮我查一下 TN20260822001 工单状态”

问答系统会查询工单表并返回最新进度。

## 二、工单状态说明

| 状态 | 含义 |
|------|------|
| `pending` | 待处理，工单已提交，等待处理人接单 |
| `processing` | 处理中，处理人已经接单并开始处理 |
| `done` | 已完成，问题已解决 |
| `closed` | 已关闭，工单结束 |

## 三、工单字段说明

- 工单号：类似 `TN20260822001`，提交后自动生成。
- 问题类型：权限申请、故障上报、咨询、投诉建议等。
- 优先级：low / normal / high / urgent。
- 处理人：当前负责处理该工单的人员。
- 更新时间：工单最后变更时间。

## 四、催办规则

- 普通工单超过 1 个工作日未处理，可以在工单系统点击「催办」。
- 紧急工单超过 30 分钟未响应，建议直接联系值班负责人。
- 重复催办不会提高优先级，建议补充更明确的问题描述。

## 五、常见问答对

### 问：我昨天提的权限申请工单处理到哪了？

答：可以登录工单系统，在「我的工单」中按提交时间查询，查看工单状态、处理人和最新回复。也可以通过问答系统提供工单号查询。

### 问：工单状态显示 pending 是什么意思？

答：表示工单已经提交成功，但还没有处理人接单。普通工单一般在 1 个工作日内处理。

### 问：工单一直没人处理怎么办？

答：可以在工单系统点击「催办」；如果是紧急问题，直接联系对应系统值班负责人。

### 问：工单显示 done 后还能继续提问吗？

答：如果问题没有完全解决，可以在原工单中继续补充信息，处理人会重新打开工单继续处理。

### 问：怎么查看历史工单？

答：进入工单系统「我的工单」页面，按时间、类型或关键字筛选即可查看历史记录。
