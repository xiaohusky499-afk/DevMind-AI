# front（DevMind-AI 前端）

React + Vite 实现，对接 `backend` 服务的接口。

## 功能

- 账号密码登录 / 注册 / 手机验证码登录
- 智能问答：正式会话、WebSocket 流式回答、RAG 检索进度与引用溯源
- 知识库：真实列表与筛选、新建/编辑、组织成员搜索、成员添加/改权/移除、归档
- 文档管理：选择目标知识库上传、类型筛选、任务自动轮询、重命名、分块预览、重新索引与删除
- 检索测试：选择知识库、配置 Top K/重排数量并查看真实检索结果
- 历史记录：搜索与分页、重命名、软删除，恢复完整问题、回答和引用上下文
- 当前用户信息与退出登录
- 个人档案、部门、职位与使用偏好的 PostgreSQL 持久化编辑
- 收藏回答与取消收藏，使用 PostgreSQL 持久化
- 系统偏好：默认知识库、回答模式、回答详略、语言与时区持久化

开发环境由 Vite 将 HTTP 与 WebSocket `/api` 请求统一代理到 `127.0.0.1:15200`。

## 启动

```powershell
cd .\front
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`。

后端地址默认 `http://127.0.0.1:15200`，可通过 `front/.env` 配置：

```text
VITE_API_BASE_URL=http://127.0.0.1:15200
```
